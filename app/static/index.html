          QUICK GUIDE
          
From zero to a routed AI call in five steps.

          
Your project only needs one OpenAI-compatible base URL. Provider selection, quota tracking, model health, and fallback stay behind The Router.

        

        

          
1
Run it
Clone the repository and run docker compose up --build. Open http://localhost:4010.

          
2
Add providers
Open Setup. Paste any API keys you have. More recurring-free providers means more capacity and better fallback coverage.

          
3
Test in Playground
Use free/auto normally, or select free/fast, free/smart, free/code, free/reasoning, free/vision, or free/long.

          
4
Point your app at it
Keep the OpenAI SDK and change its base URL to http://localhost:4010/v1. The client API key can be a placeholder such as local.

          
5
Watch routing
Providers shows supported quota telemetry and model health. Usage & traces shows each fallback attempt. Catalog review shows upstream model changes before they become routable.
