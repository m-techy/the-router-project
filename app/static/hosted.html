One API over your free AI capacity.

The Router combines recurring free LLM providers behind one OpenAI-compatible endpoint, then routes by capability, quota headroom, health and latency—without silently spending money.

View on GitHub Self-host locally

Free-first routing

Persistent free pools are the default. Trials and temporary promotions require explicit opt-in.

OpenAI compatible

Use existing OpenAI SDK clients with virtual models such as free/auto, free/fast and free/code.

Dashboard + playground

Self-hosted mode includes provider setup, health probes, quota visibility, route previews, request traces and an interactive playground.

RUN LOCALLY 
git clone https://github.com/m-techy/the-router-project.git
cd the-router-project
cp .env.example .env
docker compose up --build

# open http://localhost:4010
