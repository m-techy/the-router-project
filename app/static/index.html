          HOW TO USE IT
          
From clone to routed request without infrastructure ceremony.

          

            The Router is meant to disappear behind your apps. Configure providers once,
            then keep using familiar OpenAI SDK calls.
          

        


        

          
1
Run native or Docker
Use start.bat / ./start.sh for the lightweight native process, or Docker when you want isolation.

          
2
Connect providers
Open Setup and add only the keys you have. No-key pools can work immediately.

          
3
Test a virtual route
Use Playground with free/auto, then inspect why a provider was chosen.

          
4
Point your app here
Keep the OpenAI SDK and change its base URL to http://localhost:4010/v1.

          
5
Watch the fallback chain
Usage & traces shows every provider attempt, latency, token count, and failure.
