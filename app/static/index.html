Run
Native first, Docker when useful.
start.bat / ./start.sh creates a reusable venv and launches the lightweight FastAPI process.

          
Connect
Add providers only once.
Use Setup for local credentials or keep them in environment variables. No-key pools are immediately visible.

          
Chat
Ask for intent, not vendor names.
Use free/auto, free/fast, free/smart, free/code, and other virtual chat routes.

          
Embed
Route text or multimodal embeddings.
POST to /v1/embeddings with embed/auto, embed/text, or embed/multimodal. Gemini handles multimodal inputs; Cloudflare adds text embedding fallback.

          
Transcribe
Route speech recognition through free Whisper capacity.
POST multipart audio to /v1/audio/transcriptions with transcribe/auto, transcribe/fast, or transcribe/accurate.

          
Observe
See every fallback.
Usage traces show failed providers, winning models, latency, tokens, and cooldown behavior across modalities.
